# Prism 彩色玻璃网站备份

备份来源：https://prism-stained-glass.zaxiquej316489.chatgpt.site/
版本：线上第 3 版，2026-09-17 备份。

使用：双击“离线版.html”，即可离线使用。图片仍在本机浏览器内处理。

index.html、app.js、glass.js、style.css、worker.js 为原始站点文件，未修改；其中原始 index.html 需通过本地 HTTP 服务器运行。
“离线版.html”将样式、脚本及 Worker 内嵌到单个文件，方便双击使用。
上一级 prism-stained-glass-v3-source.zip 保存原始源码归档（包括部署配置）。
backup-info.json 记录版本、提交标识及原始文件 SHA-256 校验值。

此备份不包含浏览器内临时上传的个人图片。
