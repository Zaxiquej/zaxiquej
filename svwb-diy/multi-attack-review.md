# 三次攻击校核（v5.00）

官方公开接口快照（2026-09-24，904 张记录）的非衍生卡中检出三张三次攻击卡：10154120 剧毒公主·美杜莎，10654110 枯渴的魔神·阿尔弭斯，10924120 武皇的变貌·贝尔铁佐。前者常驻、第二张超进化获得，第三张搭配低攻击疾驰。进化获得是从时点与能力独立组合出的原创变体。

参照：[美杜莎官方图鉴](https://shadowverse-wb.com/ja/deck/cardslist/card/?card_id=10154120)。另外两张从本地 reference.json 中的官方公开接口数据核对；此次网页抓取仅返回它们的页面外壳，不作为网页正文证据。

实现：三次攻击仍限 7+ 虹卡；常驻、进化、超进化分别计价；8+ 可与疾驰组合。攻击、交战触发的现有收益补收两次，后续触发按三次估值。三次攻击本身按最终攻击力非线性计价，已有虹吸／屏障／潜行也补收多次战斗价值。疾驰按总攻击伤害约束，不把低攻击三连击当作无效的低攻击单次疾驰，也不允许高攻击逃过整体预算。各模块仍独立选取，不复刻整套官方卡。

验证：30,000 个通用种子；30,000 个稀有战斗样本加 4,400 个集中高费虹卡样本（其中 1,200 个究极混乱）；网页与 Node 结果一致、三种时点显示顺序与复制文本通过。具体覆盖与例子见 multi-attack-validation.json、multi-attack-examples.json。集中样本的比例不是全随机概率。

额外运行的旧 composition-test.cjs 在“所有组件原始估值之和必须等于整段原始估值”的断言失败：效果拆分196 是敌方进场被动，单次组件值 5.4，整段循环值 17.28，数据明确另记 occurrenceRaw；没有多次攻击。继续检查还发现弃手收益／手牌轮转包装有独立代价或费用，旧断言未区分。这次没有为让旧断言通过而改动这些现有模型；卡文合并、排序的定例检查在此断言前已通过。
