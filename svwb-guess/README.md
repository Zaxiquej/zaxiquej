# 影之诗2猜卡

入口：`../guessWB.html`。独立实现，不修改一代的 `guess.js`、`similarity.js` 或 DIY 数据。

直接打开 HTML 或通过静态服务器访问即可。卡池、搜索、排名都在本地；卡图通过官网公开图片 URL 按需加载，图片失败时保留文字详情。支持手机、键盘提交、简繁搜索、同名候选、筛选、种子、提示、揭晓、前 20 名挑战和本机自动续局。今日种子使用玩家本地日期；相同数据版本、种子、卡池选项得到相同谜底。刷新数据会使旧局失效。

## 数据

`node svwb-guess/sync.cjs` 从官方公开 `GET /web/CardList/cardList?include_token=1&offset=…` 获取简体中文卡池（`Lang: chs`）。每页 30 张，最多并发 2 个请求；检查分页覆盖及总数一致后才替换 `data.js`。保存原始卡牌 ID、关联卡、指定可用标志、进化前后文本、纹章/激奏/结晶/信仰附属效果。不加入嵌套的基础系列变体或异画列表。

二代 API 的 `type`：1 随从，2 护符，3 吟唱护符，4 法术。不能套用一代编号。特殊效果类型：1 纹章，2 结晶，3 激奏，4 信仰。附属效果参与来源卡的比较，不独立抽成谜底。指定池沿 `related_card_ids` 做闭包，然后按用户选项排除衍生卡。

## 相似度

备选卡名点击即提交猜测，“详情”按钮仅查看卡牌。效果包含/排除输入支持空格（含连续空白、全角空格）分词；包含使用 AND，排除使用 OR，每个词分别进行简繁与文字规范化，忽略空词。

费用筛选沿用一代的“比较方式 + 数字”控件，支持等于、以上（含该费用）、以下（含该费用）；留空不限，清空筛选会恢复等于。

最新一条猜测/提示记录固定置顶、黄色高亮并标注“最新”；其他记录按所选的接近名次或最近猜测排序。切换排序和刷新续局不改变置顶规则。

沿用一代的 20% 基础、60% 机制、20% 描述配比；二代重新提取机制，不使用一代的预处理词条。

- 基础：职业、种类、费用、稀有度、类型与随从身材。护符两个子类归为同一大类，吟唱在机制部分区分。
- 机制：带触发时点、对象和数值的加权交集/并集。进化和超进化、回费与跳费、对敌伤害和自伤分开；启动费用单独比较；纹章等附属文本按独立上下文、0.7 倍权重参与。重复进化文本不重复累计。关联卡名提供少量加分，自身名称不参与。
- 近似关联：`semantics.js` 为回手、破坏、消失等解场方式，以及抽牌/检索、召唤/生成、回费/减费、回复/防护等提供部分关联。敌方回手同时保留与敌方解场的用途关联、与己方回手的动作关联；敌方解场还按目标和范围共享用途特征。进化时与超进化时的触发匹配系数为 0.8，完全相同时为 1，无关时点为 0.6；这不是整张卡的最终相似度。
- 关联会考虑敌我、区域、目标、范围、触发事件、来源与数值，使用一对一最大权重匹配，防止同一效果反复加分。机制分为 `精确特征分 + (1 - 精确特征分) × 0.35 × 关联分`，既保留不同机制的区别，也让效果接近的卡获得有限加分。返回手牌/牌组的去向不当成被选目标的区域。
- 参考一代 `similarity.js` 的目标、条件、时点及用途拆分：单体／指定多体／随机／全体写入主要作用特征；单体与全体的关联系数为 0.3；自我强化、对其他对象强化及手牌／牌组强化分开。伤害提供较低权重的解场用途，主战者伤害不计入随从解场。
- 自带关键词与之后获得的关键词共享能力结果，同时保留时点和获得方式差异；独立成行的疾驰等不继承上一段入场曲时点。进化与超进化还共享部分触发类别特征。
- 提取 `若…则…` 与连击等条件；条件不同降低匹配度。带“改为”的条件升级按半权重计入，避免把升级分支当作必定额外发动一次的效果。`发动与【入场曲】相同的能力` 等明确引用先展开到其实际触发时点，拒绝循环展开。
- 重复触发同时保留低权重的结构特征（语义权重 0.35）：既可匹配其他重复同一时点能力的卡，也可按展开后的效果匹配直接写出类似能力的卡；实际效果仍是主要部分。
- 描述：去掉自身名称、替换引用卡名后的中文二字片段，保留具体数值，使用卡池内逆文档频率加权交并比，避免常用套话占过大比重。
- 效果数值：同时考虑绝对差与比例差，匹配系数为 `sqrt((min(|a|,|b|)+1)/(max(|a|,|b|)+1)) / (1+0.55×|a-b|)`；例如 1 对 4 约为 0.239，3 对 4 约为 0.577。主要效果特征、近似效果与双方均为伤害的解场用途都应用该系数，避免无数值的用途加分绕过扣分；伤害与消失等不同作用不比较数值。费用与基础身材仍使用原有基础分公式。

这是可解释的启发式模型，不是规则引擎。条件、目标指代、多段嵌套能力可能提取不完全；不宣称语义等价或对战强度。答案固定 100 分，其余最高 99.99；同分按 ID 稳定排序，避免答案被另一张功能相同的卡挤出第 1 名。

一代可直接使用 `skill_option`、`skill_condition`、`skill_target` 等结构化词条；当前二代本地数据主要是效果文字，不能直接套用一代的全部规则和卡牌专属权重。尚未完整处理跨句条件延续、复杂目标指代、召唤物能力递归及变身／模式分支；这里保留独立附属效果比较，不无限展开衍生关系。

提示只给比当前最佳排名更靠前、尚未出现且不是答案的卡。猜测和提示分开计数。查看前 20 名榜单会结束前 20 名挑战，避免边看榜边计为挑战。

## 验证

`node svwb-guess/test.cjs` 检查类型、超进化、启动费用、敌我目标、纹章内容、重复进化文本、卡池闭包、种子稳定性、排名与提示单调性。页面脚本：`node --check svwb-guess/app.js`。

`node svwb-guess/semantic-test.cjs` 检查解场与资源等关联、敌我回手、进化/超进化时点的分级接近、错误区域与否定词、匹配的对称性和上限，并输出塞尔文的实际解场近邻。

另含阿尔菲德的排序回归：曲千代在双刀哥布林、艾塞克莱因之前，奥丁在阿波罗之前；覆盖条件升级、单体／多体／AOE、重复触发引用及自身／区域强化。

## 隐藏测试面板

点击页面空白处，然后连续输入 `iamkmr`（相邻按键间隔不超过 3 秒，输入框内不触发）。开局前、游戏中均可打开，Esc 或关闭按钮退出。面板由独立的 `debug.js` 实现，不读写谜底、猜测记录或存档。

搜索卡名／ID、选择卡牌或按上一张／下一张，查看最接近的 100 张（含自身）。可选所有卡牌或非衍生卡池；测试对象始终可从全部 904 张卡中选取，若其为衍生卡，则非衍生卡池额外包含该测试对象。每行显示基础／机制／文字分与加权总分；展开卡名可看卡文、识别结果与共同特征。普通游戏的榜单与挑战仍仅前 20 名。
